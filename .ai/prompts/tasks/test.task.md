## Вхідні дані (заповни перед відправкою)

- **Що перевірити:** `<артефакт, файл або функціональність>`
- **Критерії якості:** `<посилання на .ai/docs/04-quality-gates.md або власний чекліст>`
- **Контекст:** `<посилання на project-state.yaml або handoff>`

## Завдання для агента

1. Прочитай артефакт(и) зазначені вище.
2. Порівняй з критеріями якості з [`.ai/docs/04-quality-gates.md`](../../docs/04-quality-gates.md).
3. Перевір наявність усіх обов'язкових полів / секцій.
4. Зафіксуй результат: `passed` або `failed` з переліком зауважень.
5. Якщо `failed` — сформуй список конкретних виправлень.

## Очікуваний результат

- Вердикт: `passed` / `failed`
- Перелік зауважень (якщо є)
- Рекомендовані виправлення (якщо `failed`)
