# Task: Research

Шаблон для запиту до Researcher — збору інформації та структурування знань.

## Вхідні дані (заповни перед відправкою)

- **Питання дослідження:** `<конкретне питання або гіпотеза>`
- **Scope:** `<вузький / широкий>` — опиши межі дослідження
- **Контекст:** `<посилання на handoff, ADR або issue>`
- **Пріоритет:** `[ ] critical  [ ] high  [ ] medium  [ ] low`
- **Output файл:** `.ai/memory/knowledge/<topic>.notes.md`

## Завдання для Researcher

1. Відповісти на питання дослідження, використовуючи доступні знання та матеріали.
2. Розрізняти факти (перевірені) від припущень (неперевірених).
3. Зафіксувати знахідки у `<output файл>`.
4. Виявити відкриті питання для подальшого дослідження.
5. Надати чітку рекомендацію (що робити на основі знахідок).

## Очікуваний результат

Структурований файл знань із секціями:

- **Питання** — точне формулювання
- **Факти** — перевірені, з джерелами
- **Припущення** — неперевірені, з позначкою `(assumption)`
- **Відкриті питання** — що потребує подальшого вивчення
- **Рекомендація** — конкретний наступний крок (UA)
