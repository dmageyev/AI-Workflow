# ADR-0002: CI-перевірка структури сесій

## Status

`accepted`

## Date

2026-05-04

## Context

Протокол handoff вимагає, щоб кожна папка сесії у `.ai/logs/sessions/` містила два файли:
`snapshot.yaml` та `handoff.md`. Без автоматичної перевірки легко випадково закомітити
папку сесії з відсутніми артефактами — що порушує continuity між агентами.

## Decision

Додати окремий CI job `session-structure` у `.github/workflows/lint.yml`, який:

1. Сканує всі піддиректорії `.ai/logs/sessions/`.
2. Перевіряє наявність `snapshot.yaml` та `handoff.md` у кожній з них.
3. Завершується з `exit 1`, якщо хоча б одна папка неповна.
4. Пропускає перевірку, якщо директорія `sessions/` ще не існує (graceful skip).

## Consequences

- Порушення handoff-протоколу виявляється автоматично на CI, а не під час наступної сесії.
- Агенти не можуть замерджити PR із неповним Handoff Package.
- Нова папка сесії (`README.md`) не вважається папкою сесії — CI перевіряє лише піддиректорії
  (не файли в корені `sessions/`).
