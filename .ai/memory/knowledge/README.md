# Knowledge Base

Ця директорія зберігає **довготривалі знання** проєкту, які залишаються актуальними
між сесіями та накопичуються з часом.

## Що зберігати тут

- Результати досліджень Researcher-агента
- Знання про предметну галузь (domain knowledge)
- Перевірені підходи, патерни, анти-патерни
- Нотатки про зовнішні системи та залежності

## Схема іменування файлів

```text
<topic>.notes.md
```

Приклади:

- `domain-notes.md` — загальні нотатки про домен проєкту
- `ci-patterns.notes.md` — знання про CI/CD підходи
- `agent-design.notes.md` — патерни проєктування агентів
- `prompting-techniques.notes.md` — техніки промптингу

## Формат файлу знань

Кожен файл має містити секції:

```markdown
# <Тема>

## Факти
- Перевірений факт 1 (джерело або дата перевірки)

## Припущення
- Неперевірений факт 1 (assumption)

## Відкриті питання
- Питання, що потребує подальшого дослідження

## Рекомендації
- Практичний висновок для агентів
```

## Як шукати знання

1. Переглянь список файлів у цій директорії.
2. Прочитай `domain-notes.md` для загального контексту.
3. Для специфічної теми — шукай відповідний `<topic>.notes.md`.

## Зв'язок із task-промптами

Для нових досліджень використовуй: [`.ai/prompts/tasks/research.task.md`](../../prompts/tasks/research.task.md)

## Різниця між knowledge та decisions

| | Knowledge (цей каталог) | Decisions (`.ai/memory/decisions/`) |
|---|---|---|
| **Що** | Знання, факти, спостереження | Архітектурні рішення (ADR) |
| **Формат** | Вільний Markdown | Структурований ADR |
| **Змінюється** | Так — доповнюється | Ні — незмінний запис |
