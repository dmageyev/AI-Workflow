# Domain Notes

Загальні нотатки про домен проєкту `AI-Workflow`.

## Ключові концепції

### Multi-agent system

Система, де кілька AI-агентів з різними ролями співпрацюють для досягнення спільної мети.
Кожен агент має свій системний промпт, обмеження та зону відповідальності.

### Consciousness transfer (передача свідомості)

Метафора для формалізованої передачі контексту між агентами або між сесіями.
Реалізується через Handoff Package (snapshot.yaml + handoff.md).

### Institutional memory

Накопичені знання проєкту, які не залежать від конкретного агента чи сесії.
Зберігаються у [`.ai/memory/knowledge/`](.), [`.ai/memory/decisions/`](../decisions/), [`.ai/memory/glossary.uk.md`](../glossary.uk.md).

## Нотатки для поповнення

Додавай сюди:

- домен-специфічні знання, що не вписуються в glossary
- контекст для нових учасників проєкту
- важливі зовнішні ресурси та посилання

## Практичні поради з використання workflow

### Як обрати правильного агента

| Задача | Агент |
|--------|-------|
| Написати/змінити файл | Worker |
| Дослідити тему або підхід | Researcher |
| Перевірити якість артефакту | Reviewer |
| Змінити структуру репозиторію | Architect |
| Координувати кілька агентів | Orchestrator |

### Типові помилки при handoff

- Не оновлено `project-state.yaml` перед створенням snapshot — стан застаріє.
- Розпочата нова сесія без закриття попередньої — порушується ланцюг контексту.
- `snapshot.yaml` зберігається без `handoff.md` — машинозчитуваний стан є, але
  людиночитаний підсумок відсутній; CI перевірка провалиться.
- Не додані `Next actions` в handoff.md — наступний агент не знає з чого починати.

### Рекомендована послідовність роботи з агентом

1. Прочитай `project-state.yaml` → обери task зі статусом `todo`.
2. Прочитай останній handoff в [`.ai/logs/sessions/`](../../logs/sessions/) → відновись у контексті.
3. Виконай задачу.
4. Оновити `project-state.yaml` (status → `done`, прогрес).
5. Створи папку сесії та handoff package.
6. Запусти Reviewer для перевірки handoff.

### Few-shot prompting у системних промптах

2-3 приклади "Запит → Відповідь" значно покращують якість відповідей агента.
Негативні приклади (що робити НЕ потрібно) менш ефективні — краще описати
позитивну поведінку явно.
