# Security Policy

## Scope

`AI-Workflow` — репозиторій-шаблон для організації мультиагентних workflows.
Він **не містить** серверного коду, API або сховищ даних кінцевих користувачів.

Тим не менш, репозиторій може використовуватися як основа для проєктів,
що обробляють чутливу інформацію. Дотримання наступних правил є обов'язковим.

## Правила безпеки

- **Не зберігай секрети в репо**: API-ключі, паролі, токени — лише через GitHub Secrets або `.env` (у `.gitignore`).
- **Не логуй чутливі дані**: у `snapshot.yaml` та `handoff.md` не повинно бути PII або credentials.
- **Перевіряй `.gitignore`**: переконайся, що `.env`, `*.key`, `*.pem` виключені перед комітом.
- **CODEOWNERS**: зміни до `.ai/` проходять рев'ю за правилами [`.github/CODEOWNERS`](.github/CODEOWNERS).

## Як повідомити про вразливість

Якщо ти виявив потенційну проблему безпеки:

1. **Не створюй публічний GitHub Issue.**
2. Надішли опис уразливості через
   [GitHub Private Vulnerability Reporting](https://github.com/dmageyev/AI-Workflow/security/advisories/new).
3. Вкажи:
   - Опис проблеми
   - Кроки для відтворення
   - Потенційний вплив

Ми розглянемо звіт і відповімо протягом **7 робочих днів**.

## Версії

Підтримується лише остання версія (гілка `main`).
Попередні версії не отримують виправлень безпеки.
