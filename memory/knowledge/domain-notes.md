# Domain Notes

Загальні нотатки про домен проєкту `AI-Workflow`.

## Ключові концепції

### Multi-agent system

Система, де кілька AI-агентів з різними ролями співпрацюють для досягнення спільної мети.
Кожен агент має свій системний промпт, обмеження та зону відповідальності.

### Consciousness transfer (передача свідомості)

Метафора для формалізованої передачі контексту між агентами або між сесіями.
Реалізується через Handoff Package (snapshot.yaml + handoff.md).

### Institutional memory

Накопичені знання проєкту, які не залежать від конкретного агента чи сесії.
Зберігаються у `memory/knowledge/`, `memory/decisions/`, `memory/glossary.uk.md`.

## Нотатки для поповнення

Додавай сюди:

- домен-специфічні знання, що не вписуються в glossary
- контекст для нових учасників проєкту
- важливі зовнішні ресурси та посилання
